CSS: представление, компоновка и визуальное оформление

CSS (Cascading Style Sheets) описывает, как HTML-документ выглядит: цвета, шрифты, отступы, сетки, адаптивность, анимации и визуальные эффекты. CSS отделяет оформление от структуры, что упрощает поддержку и повторное использование стилей.

КаскадСелекторыКомпоновкаАнимации

1. Что такое CSS и за что он отвечает

CSS — язык описания представления документа. Он определяет визуальное оформление HTML-элементов: цвета, размеры, отступы, расположение на странице, анимации и реакцию на состояния.

CSS не является языком программирования: в нём нет переменных в привычном смысле (хотя custom properties близки к ним), циклов и функций общего назначения. CSS описывает правила: «если элемент соответствует селектору, примени к нему указанные свойства».

HTML

Структура и семантика документа.

CSS

Визуальное оформление и компоновка.

JavaScript

Поведение и взаимодействие с пользователем.

CSS развивается через спецификации W3C. Модули CSS описывают отдельные возможности: Flexbox, Grid, анимации, переменные и другие. Браузеры реализуют эти модули с разной скоростью, поэтому важно проверять совместимость.

2. Синтаксис CSS

CSS состоит из правил (rules). Каждое правило содержит селектор и блок объявлений (declarations).

/* Селектор выбирает элементы, блок объявлений задаёт их оформление */
h1 {
  color: royalblue;
  font-size: 2rem;
  margin-bottom: 1rem;
}

2.1. Селектор и блок объявлений

  • Селектор определяет, к каким элементам применяется правило.
  • Объявление состоит из свойства и значения, разделённых двоеточием.
  • Объявления разделяются точкой с запятой.
  • Блок объявлений заключается в фигурные скобки.
/* Несколько селекторов могут разделяться запятой */
h1, h2, h3 {
  font-family: system-ui, sans-serif;
  line-height: 1.2;
}

/* Несколько свойств в одном правиле */
.card {
  padding: 1rem;
  border: 1px solid #dce2ef;
  border-radius: 0.5rem;
  background: white;
}

2.2. Комментарии

/* Это комментарий. Он игнорируется браузером. */
.button {
  /* Временное отключение свойства */
  /* background: red; */
  background: blue;
}

2.3. @-правила

CSS включает специальные конструкции, начинающиеся с символа @. Они управляют импортом стилей, медиа-запросами, ключевыми кадрами анимаций и другими аспектами.

@import url("other.css");

@media (width >= 48rem) {
  .layout { grid-template-columns: 1fr 1fr; }
}

@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

@property --progress {
  syntax: "<number>";
  inherits: false;
  initial-value: 0;
}

3. Селекторы CSS

Селекторы выбирают элементы, к которым применяются стили. CSS предоставляет широкий набор селекторов: от простых типов до сложных комбинаций и псевдоклассов.

Тип селектораПримерОписание
ТипpВсе элементы p.
Класс.cardЭлементы с классом card.
ID#headerЭлемент с id="header".
Атрибут[type="text"]Элементы с указанным атрибутом.
Универсальный*Все элементы.
Потомокarticle pВсе p внутри article.
Дочернийul > liПрямые дочерние li элемента ul.
Соседнийh2 + pПервый p сразу после h2.
Общий соседнийh2 ~ pВсе p после h2 на том же уровне.
Псевдокласс:hover, :focus, :first-childЭлементы в определённом состоянии.
Псевдоэлемент::before, ::afterГенерируемое содержимое до или после элемента.
 
/* Комбинации селекторов */
nav > ul > li > a:hover {
  color: royalblue;
  text-decoration: underline;
}

/* Псевдоклассы состояний */
button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

/* Псевдоэлементы */
.quote::before {
  content: "«";
  color: gray;
}

/* Селекторы атрибутов */
input[type="email"] {
  border-color: royalblue;
}

a[href^="https"] {
  /* Ссылки, начинающиеся с https */
  background: url("lock-icon.svg") no-repeat right center;
}

3.1. Современные псевдоклассы

ПсевдоклассНазначение
:is()Принимает список селекторов, выбирает элементы, подходящие под любой из них.
:where()Как :is(), но с нулевой специфичностью.
:has()Выбирает элемент, если он содержит подходящие потомки или соседей.
:focus-visibleЭлемент в фокусе, полученном с клавиатуры.
:focus-withinЭлемент, внутри которого находится элемент в фокусе.
:checkedВыбранный checkbox или radio.
:placeholder-shownПоле ввода, в котором отображается placeholder.
:valid, :invalidПоле ввода с корректными или некорректными данными.
 
/* :is() упрощает сложные селекторы */
:is(h1, h2, h3, h4) + p {
  margin-top: 0.5rem;
}

/* :has() — «родительский селектор» */
.card:has(img) {
  grid-template-rows: auto 1fr;
}

/* :focus-visible для клавиатурной навигации */
button:focus-visible {
  outline: 3px solid royalblue;
  outline-offset: 2px;
}

4. Специфичность и каскад

Когда к одному элементу применяется несколько правил с одинаковыми свойствами, браузер определяет, какое правило победит, на основе специфичности, источника и порядка объявлений.

4.1. Специфичность

Специфичность — числовое значение, которое вычисляется для каждого селектора. Оно определяет приоритет правила при конфликте свойств.

Тип селектораВклад в специфичность
Inline-стили (style="...")1000 (или A=1)
ID (#id)100 (или A=1)
Классы, атрибуты, псевдоклассы (.class, [attr], :hover)10 (или B=1)
Типы элементов, псевдоэлементы (div, ::before)1 (или C=1)
Универсальный селектор (*), комбинаторы0
 
/* Специфичность: 0-0-1 (один тип) */
p { color: black; }

/* Специфичность: 0-1-0 (один класс) */
.text { color: blue; }

/* Специфичность: 1-0-0 (один ID) */
#intro { color: red; }

/* Специфичность: 0-1-1 (класс + тип) */
p.text { color: green; }

/* Специфичность: 1-1-1 (ID + класс + тип) */
#intro p.text { color: purple; }

4.2. Каскад

Каскад — алгоритм разрешения конфликтов между объявлениями. Он учитывает:

  1. Источник: user-agent (браузер), user (пользователь), author (автор страницы). Обычно авторские стили имеют наивысший приоритет.
  2. Важность: объявления с !important переопределяют обычные объявления (но !important в user-стилях имеет приоритет над !important в author-стилях).
  3. Специфичность: более специфичные селекторы побеждают.
  4. Порядок: при равной специфичности побеждает последнее объявление в исходном коде.
/* Каскад в действии */
p { color: black; }        /* Специфичность: 0-0-1 */
.text { color: blue; }     /* Специфичность: 0-1-0 — побеждает */
#intro { color: red; }     /* Специфичность: 1-0-0 — побеждает всё */

/* !important переопределяет специфичность */
p { color: black !important; }  /* Побеждает, даже если есть #intro */
Избегай !important. Оно затрудняет сопровождение и отладку. Вместо этого увеличивай специфичность селекторов или реорганизуй CSS так, чтобы правила применялись в правильном порядке.

4.3. Наследование

Некоторые CSS-свойства наследуются от родителя к потомкам. Например, color, font-family, line-height наследуются. Другие свойства, такие как margin, padding, border, не наследуются.

body {
  font-family: system-ui, sans-serif;
  color: #172033;
}

/* Все дочерние элементы унаследуют font-family и color */
article {
  /* Явное наследование, если нужно переопределить */
  color: inherit;
}

Ключевое слово inherit принудительно наследует значение от родителя. initial сбрасывает свойство к начальному значению. unset ведёт себя как inherit для наследуемых свойств и как initial для ненаследуемых.

5. Блочная модель (Box Model)

Каждый HTML-элемент представляется в виде прямоугольной коробки (box). Блочная модель описывает, как вычисляются размеры этой коробки: ширина, высота, отступы, границы и внешние отступы.

СвойствоНазначение
width, heightШирина и высота содержимого (content).
paddingВнутренние отступы между содержимым и границей.
borderГраница вокруг содержимого и padding.
marginВнешние отступы между элементом и соседями.
 
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #dce2ef;
  margin: 16px;
}

/* Вычисленная ширина: 300 + 20*2 + 2*2 = 344px (content-box) */

5.1. box-sizing

По умолчанию width и height задают размер только содержимого (content-box). Padding и border добавляются к этому размеру, что делает расчёты непредсказуемыми.

Свойство box-sizing: border-box включает padding и border в общую ширину и высоту элемента, что делает расчёты размеров гораздо более предсказуемыми.

/* Глобальное применение border-box */
*, *::before, *::after {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #dce2ef;
}

/* Вычисленная ширина: 300px (border-box) */
/* Содержимое: 300 - 20*2 - 2*2 = 256px */

5.2. Margin collapse

Вертикальные margin соседних блочных элементов могут «схлопываться»: вместо суммы берётся большее значение. Это не происходит для горизонтальных margin, flex- и grid-элементов.

.first { margin-bottom: 20px; }
.second { margin-top: 30px; }

/* Расстояние между элементами: 30px, а не 50px */

6. Компоновка: Flexbox и Grid

CSS предоставляет две мощные системы компоновки: Flexbox для одномерных раскладок (строка или колонка) и Grid для двумерных раскладок (строки и столбцы одновременно).

6.1. Flexbox

Flexbox управляет расположением элементов вдоль одной оси (горизонтальной или вертикальной). Он идеально подходит для навигации, панелей инструментов, карточек в ряд и других одномерных раскладок.

.container {
  display: flex;
  flex-direction: row; /* или column */
  justify-content: space-between; /* выравнивание по главной оси */
  align-items: center; /* выравнивание по поперечной оси */
  gap: 1rem; /* расстояние между элементами */
}

.item {
  flex: 1; /* элемент растёт, чтобы заполнить пространство */
}
Свойство контейнераНазначение
flex-directionНаправление главной оси: row, column, row-reverse, column-reverse.
justify-contentВыравнивание по главной оси: flex-start, center, space-between, space-around, space-evenly.
align-itemsВыравнивание по поперечной оси: stretch, center, flex-start, flex-end, baseline.
flex-wrapПеренос элементов на новую строку: nowrap, wrap, wrap-reverse.
gapРасстояние между flex-элементами.
Свойство элементаНазначение
flex-growКоэффициент роста элемента при наличии свободного пространства.
flex-shrinkКоэффициент сжатия элемента при нехватке пространства.
flex-basisНачальный размер элемента до распределения пространства.
flexСокращение для flex-grow, flex-shrink, flex-basis.
align-selfИндивидуальное выравнивание элемента по поперечной оси.

6.2. CSS Grid

Grid управляет расположением элементов в двумерной сетке: строки и столбцы одновременно. Он подходит для сложных раскладок страницы, каталогов, дашбордов и других двумерных структур.

.grid-container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* три столбца */
  grid-template-rows: auto 1fr auto; /* три строки */
  gap: 1rem;
}

.header { grid-column: 1 / -1; } /* на всю ширину */
.sidebar { grid-row: 2 / 3; }
.main { grid-column: 2 / 3; grid-row: 2 / 3; }
Свойство контейнераНазначение
grid-template-columnsОпределение столбцов: размеры, fr, repeat(), minmax().
grid-template-rowsОпределение строк.
grid-template-areasИменованные области сетки.
gapРасстояние между ячейками.
justify-items, align-itemsВыравнивание элементов внутри ячеек.
justify-content, align-contentВыравнивание всей сетки внутри контейнера.
Свойство элементаНазначение
grid-columnПозиция элемента по столбцам: 1 / 3, span 2.
grid-rowПозиция элемента по строкам.
grid-areaИмя области или сокращение для column/row.
 
/* Автоматическая адаптивная сетка */
.card-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1rem;
}

/* Именованные области */
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
}

7. Позиционирование

Свойство position управляет тем, как элемент располагается относительно других элементов и viewport.

ЗначениеПоведение
staticОбычное расположение в потоке документа (по умолчанию).
relativeЭлемент остаётся в потоке, но может быть смещён относительно своей обычной позиции.
absoluteЭлемент удаляется из потока и позиционируется относительно ближайшего позиционированного предка.
fixedЭлемент позиционируется относительно viewport и остаётся на месте при прокрутке.
stickyЭлемент ведёт себя как relative, пока не достигнет указанной позиции при прокрутке, затем становится fixed.
 
/* Относительное позиционирование */
.badge {
  position: relative;
  top: -10px;
  left: 5px;
}

/* Абсолютное позиционирование */
.card {
  position: relative; /* создаёт контекст позиционирования */
}

.card__badge {
  position: absolute;
  top: 0;
  right: 0;
}

/* Фиксированная шапка */
.header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 100;
}

/* Липкий заголовок */
.section-title {
  position: sticky;
  top: 0;
  background: white;
}

7.1. Z-index и stacking context

Свойство z-index управляет порядком наложения позиционированных элементов. Оно работает только для элементов с position, отличным от static.

.modal {
  position: fixed;
  z-index: 1000;
}

.overlay {
  position: fixed;
  z-index: 999;
}

Stacking context — изолированная область, внутри которой z-index определяет порядок наложения. Новые stacking context создаются элементами с position и z-index, opacity меньше 1, transform, filter и другими свойствами.

8. Единицы измерения

CSS поддерживает множество единиц измерения для размеров, отступов, шрифтов и других значений.

ЕдиницаТипОписание
pxАбсолютнаяПиксели. Не масштабируется при изменении размера текста пользователем.
emОтносительнаяОтносительно размера шрифта родителя.
remОтносительнаяОтносительно размера шрифта корневого элемента (html).
%ОтносительнаяПроцент от размера родителя или другого значения.
vw, vhViewportПроцент от ширины/высоты viewport.
vmin, vmaxViewportПроцент от меньшей/большей стороны viewport.
chОтносительнаяШирина символа «0» текущего шрифта.
frGridДоля свободного пространства в Grid.
 
/* Абсолютные единицы */
.icon { width: 24px; height: 24px; }

/* Относительные единицы */
body { font-size: 16px; }
h1 { font-size: 2rem; } /* 32px */
.card { padding: 1.5em; } /* относительно font-size карточки */

/* Viewport units */
.hero { height: 100vh; }
.title { font-size: 5vw; }

/* Функции вычислений */
.container {
  width: calc(100% - 2rem);
  font-size: clamp(1rem, 2vw, 2rem);
  padding: min(2rem, 5vw);
  margin: max(1rem, 3vh);
}
Рекомендация: для размеров шрифтов используй rem или em, чтобы пользователи могли масштабировать текст. Для отступов и размеров элементов используй rem, % или viewport units в зависимости от контекста.

9. Цвета и градиенты

CSS поддерживает множество способов задания цветов: именованные цвета, HEX, RGB, HSL, современные цветовые пространства и градиенты.

9.1. Способы задания цвета

/* Именованные цвета */
color: royalblue;
color: rebeccapurple;

/* HEX */
color: #3157c8;
color: #3157c8ff; /* с альфа-каналом */

/* RGB и RGBA */
color: rgb(49, 87, 200);
color: rgba(49, 87, 200, 0.8);

/* HSL и HSLA */
color: hsl(225, 60%, 49%);
color: hsla(225, 60%, 49%, 0.8);

/* Современные цветовые пространства */
color: oklch(0.5 0.2 250);
color: color(display-p3 0.2 0.4 0.8);

/* Функции манипуляции цветом */
color: color-mix(in srgb, royalblue 50%, white);
background: light-dark(white, #171c28);

9.2. Градиенты

/* Линейный градиент */
background: linear-gradient(135deg, #3157c8, #172033);

/* Радиальный градиент */
background: radial-gradient(circle at center, #3157c8, transparent);

/* Конический градиент */
background: conic-gradient(from 0deg, red, yellow, lime, cyan, blue, magenta, red);

/* Повторяющиеся градиенты */
background: repeating-linear-gradient(45deg, #3157c8, #3157c8 10px, #172033 10px, #172033 20px);

10. Типографика и текст

CSS предоставляет обширные возможности для оформления текста: шрифты, размеры, интервалы, выравнивание, декор и современные функции управления переносами.

СвойствоНазначение
font-familyСемейство шрифтов.
font-sizeРазмер шрифта.
font-weightНасыщенность: 100–900, normal, bold.
font-styleОбычное, курсивное или наклонное начертание.
line-heightВысоту строки.
letter-spacingМежбуквенное расстояние.
word-spacingРасстояние между словами.
text-alignВыравнивание текста.
text-decorationПодчёркивание, перечёркивание и другие линии.
text-transformПреобразование регистра отображаемого текста.
white-spaceОбработка пробелов и переносов строк.
overflow-wrap, word-breakПеренос длинных слов и последовательностей.
text-overflowОтображение обрезанного текстового содержимого.
 
body {
  font-family: Inter, system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

.article {
  max-width: 70ch;
  text-wrap: pretty;
}

10.1. Подключение собственных шрифтов

@font-face {
  font-family: "Project Sans";
  src: url("/fonts/project-sans.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

@font-face объявляет шрифт, который браузер может загрузить и использовать. Нужно учитывать лицензии, объём файлов, подмножества символов, fallback-шрифты и стратегию отображения до загрузки шрифта.

10.2. Writing modes и логические свойства

Свойства writing-mode, direction и text-orientation позволяют учитывать разные направления письма. Логические свойства — margin-inline-start, padding-block, border-inline-end, inset-inline — привязывают оформление к понятиям inline/block, а не к физическим left/right/top/bottom. Это упрощает поддержку RTL-языков и вертикального письма.

11. Фоны, рамки, тени и визуальные эффекты

CSS включает большое семейство свойств для оформления поверхностей и визуальных слоёв.

11.1. Фоны и градиенты

.hero-panel {
  background-color: #1d3268;
  background-image:
    radial-gradient(circle at top right, #7894ff, transparent 40%),
    linear-gradient(120deg, #142347, #3157c8);
  background-position: center;
  background-size: cover;
}

Можно задавать несколько фоновых слоёв, изображения, повторение, размер, позицию и способ смешивания.

11.2. Границы и тени

.panel {
  border: 1px solid #dce2ef;
  border-radius: 1rem;
  box-shadow: 0 1rem 2rem rgb(20 35 70 / 12%);
}

Дополнительно доступны outline, контуры, рамки изображений, внутренние и внешние тени, индивидуальный радиус углов и свойства для управления фоном внутри границы.

11.3. Маски, обрезка и фильтры

.avatar {
  width: 8rem;
  aspect-ratio: 1;
  object-fit: cover;
  clip-path: circle(50%);
}

.photo:hover {
  filter: saturate(1.15) contrast(1.05);
}

К инструментам эффектов относятся filter, backdrop-filter, clip-path, mask, mix-blend-mode, background-blend-mode и различные SVG-фильтры. Их следует применять осмысленно: сложные фильтры и большие полупрозрачные поверхности могут увеличивать нагрузку на графический конвейер.

12. Адаптивный дизайн — Responsive Design

Адаптивный интерфейс подстраивается под доступное пространство и условия устройства. Он должен оставаться читаемым и управляемым не только на конкретной модели телефона, но и при изменении ширины окна, масштаба, ориентации и настроек пользователя.

12.1. Mobile-first

Один из распространённых подходов — сначала описать базовый вариант для узкого экрана, а затем добавлять улучшения по мере появления свободного пространства.

/* Базовый вариант — одна колонка */
.layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* Когда пространства достаточно — две колонки */
@media (width >= 48rem) {
  .layout {
    grid-template-columns: 16rem minmax(0, 1fr);
  }
}

Breakpoints стоит выбирать по моменту, когда конкретный контент перестаёт удобно помещаться, а не только по названиям устройств.

12.2. Media Queries

Media queries позволяют применить CSS при выполнении условий о viewport, типе устройства вывода и предпочтениях пользователя.

/* Портретная ориентация */
@media (orientation: portrait) {
  .sidebar { display: none; }
}

/* Пользователь предпочитает тёмную палитру */
@media (prefers-color-scheme: dark) {
  :root {
    color-scheme: dark;
    --surface: #171c28;
    --text: #edf1f8;
  }
}

/* Пользователь просит уменьшить движение */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    scroll-behavior: auto;
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

Другие полезные media features: width, height, aspect-ratio, resolution, hover, pointer, prefers-contrast, forced-colors и print.

12.3. Container Queries

Media query обычно проверяет характеристики viewport или устройства. Container query позволяет компоненту адаптироваться к размеру своего контейнера. Это особенно полезно для повторно используемых карточек и виджетов: одна карточка может находиться в узкой боковой панели или в широком основном столбце.

.card-list {
  container-type: inline-size;
  container-name: cards;
}

.card {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

@container cards (width >= 36rem) {
  .card {
    grid-template-columns: 10rem minmax(0, 1fr);
  }
}

Единицы cqw, cqh, cqi и cqb позволяют задавать длины относительно query-контейнера. Для проверки размера контейнера требуется соответствующий containment-контекст, например container-type: inline-size.

12.4. Progressive Enhancement и @supports

.card {
  display: block;
}

@supports (display: grid) {
  .card-list {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr));
  }
}

Прогрессивное улучшение означает, что базовый интерфейс остаётся пригодным, а современные возможности добавляются там, где браузер их поддерживает. Для проверки реальной поддержки конкретной функции используй таблицы совместимости, а не только наличие свойства в черновике стандарта.

13. Состояния элементов и интерактивные интерфейсы

CSS может менять оформление в ответ на состояние элемента, не выполняя JavaScript. Это не заменяет программную логику, но позволяет оформлять фокус, наведение, выбор, валидацию и некоторые состояния взаимодействия.

button {
  background: #3157c8;
  color: white;
  border: 0;
  border-radius: .6rem;
  padding: .7rem 1rem;
}

button:hover { background: #2547ad; }
button:active { transform: translateY(1px); }
button:focus-visible {
  outline: 3px solid #f0b429;
  outline-offset: 3px;
}

input:checked + label { font-weight: 700; }
input:disabled { opacity: .55; }

13.1. Акцент, курсор и события указателя

cursor задаёт вид курсора; pointer-events управляет тем, как элемент может быть целью указательных событий; accent-color задаёт акцентный цвет некоторых встроенных управляющих элементов. Свойство appearance влияет на нативное оформление контролов, но полное переоформление форм требует внимательной работы с доступностью и состояниями.

13.2. Псевдоклассы интерактивности

Особенно полезны :focus-visible, :focus-within, :checked, :disabled, :enabled, :required, :valid, :invalid, :placeholder-shown, :target и :has().

Не убирай outline без замены. Видимый фокус нужен людям, управляющим сайтом клавиатурой. Визуальная индикация должна сохраняться и быть различимой.

14. Трансформации, переходы и анимации

CSS позволяет изменять визуальное состояние элементов плавно, по времени или по ключевым кадрам.

14.1. Transforms

.card:hover {
  transform: translateY(-4px) scale(1.02);
}

.logo {
  transform: rotate(-6deg);
  transform-origin: center;
}

Трансформации включают перенос, масштабирование, вращение и наклон в 2D/3D. Связанные свойства: transform-origin, transform-style, perspective и backface-visibility.

14.2. Transitions

.button {
  background: royalblue;
  transform: translateY(0);
  transition:
    background-color 160ms ease,
    transform 160ms ease;
}

.button:hover {
  background: midnightblue;
  transform: translateY(-2px);
}

Переход интерполирует изменение значения между состояниями. Основные свойства: transition-property, transition-duration, transition-timing-function и transition-delay.

14.3. @keyframes и animation

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }
}

.status-dot {
  animation: pulse 1.4s ease-in-out infinite;
}

Анимации могут управлять длительностью, задержкой, направлением, количеством повторений, режимом заполнения и состоянием воспроизведения. Для декоративного движения нужно учитывать prefers-reduced-motion.

14.4. Scroll-driven animations и View Transitions

Современная CSS-платформа расширяет анимации за пределы обычного времени. Scroll-driven animations связывают прогресс анимации с прокруткой или видимостью элемента. View Transitions позволяют оформлять переходы между визуальными состояниями страницы; для полноценного управления переходом между состояниями обычно используется соответствующий браузерный API.

Эти возможности развиваются, а поддержка может отличаться по браузерам и версиям. Перед применением в критичном интерфейсе проверяй совместимость и предусматривай спокойный статический вариант.

15. Современные и продвинутые возможности CSS

Современный CSS — это не только Flexbox и Grid. В нём есть средства управления архитектурой стилей, областью действия, анимационными состояниями, геометрией, содержимым и взаимодействием с другими частями платформы.

15.1. CSS Nesting

.card {
  padding: 1rem;

  &:hover {
    border-color: royalblue;
  }

  .card__title {
    font-size: 1.25rem;
  }

  @media (width >= 50rem) {
    padding: 2rem;
  }
}

Вложенность позволяет держать связанные правила рядом. Не стоит строить чрезмерно глубокие цепочки: они затрудняют чтение и могут повышать специфичность вложенных селекторов.

15.2. @property

@property --progress {
  syntax: "<number>";
  inherits: false;
  initial-value: 0;
}

.meter {
  --progress: 0.6;
  transform: scaleX(var(--progress));
  transform-origin: left;
}

Регистрация сообщает браузеру допустимый тип пользовательского свойства и другие правила его обработки. Это позволяет браузеру лучше понимать значение, а в подходящих случаях — интерполировать его в анимациях.

15.3. Anchor Positioning

Anchor positioning предназначен для привязки элемента к другому элементу-якорю, например для позиционирования подсказки около кнопки. Это отдельный механизм CSS, а не просто комбинация абсолютного позиционирования и вручную рассчитанных координат. Из-за разной поддержки браузерами его следует считать продвинутой возможностью и проверять совместимость перед использованием.

15.4. Печатные стили

@media print {
  nav, .toolbar, .no-print {
    display: none !important;
  }

  body {
    color: black;
    background: white;
  }

  a {
    color: inherit;
    text-decoration: underline;
  }
}

@page {
  margin: 18mm;
}

16. Организация и архитектура CSS в проекте

CSS-файл может быстро превратиться в набор конфликтующих правил, если не договориться о структуре. Архитектура нужна для управляемости, повторного использования и предсказуемого каскада.

16.1. Разделение по назначению

styles/
  01-reset.css
  02-tokens.css
  03-base.css
  04-layout.css
  components/
    button.css
    card.css
    navigation.css
  utilities.css
  main.css

Это пример возможной структуры, а не обязательное правило. Для небольшого сайта может быть достаточно одного файла; для большой системы полезно разделять базовые стили, компоненты и дизайн-токены.

16.2. Подходы к именованию

  • BEM: блок, элемент и модификатор, например card, card__title, card--featured.
  • Utility classes: небольшие классы-утилиты, например text-center или mt-2.
  • Component-based: стили организуются вокруг повторно используемых UI-компонентов.
  • CSS Modules: механизм сборки, который локализует имена классов; это не отдельная функция языка CSS.

16.3. Препроцессоры и PostCSS

Sass/SCSS, Less и инструменты PostCSS расширяют или преобразуют CSS на этапе сборки. Они могут предоставлять дополнительные функции, переменные, миксины, преобразование синтаксиса и автопрефиксер. Не путай возможности языка CSS с возможностями инструмента сборки: браузер получает итоговый CSS, если только браузер не поддерживает исходную конструкцию нативно.

Практический ориентир: сначала изучи нативные CSS — каскад, custom properties, Grid, Flexbox, media/container queries. Затем станет понятнее, какую проблему решает конкретная библиотека или препроцессор.

17. Доступность, производительность и отладка

17.1. Доступность

  • Сохраняй заметный клавиатурный фокус; используй :focus-visible.
  • Проверяй контраст текста и фона.
  • Не передавай состояние только цветом.
  • Уважай prefers-reduced-motion.
  • Проверяй страницу при увеличении масштаба и изменении размера текста.
  • Не меняй визуальный порядок так, чтобы он противоречил порядку чтения и фокуса.
  • Не скрывай важное содержимое только ради визуального эффекта.

17.2. Производительность

Изменение разных CSS-свойств может запускать разную работу браузера. Изменение ширины или положения в обычном потоке может потребовать пересчёта layout; изменение цвета часто требует paint; некоторые трансформации могут быть обработаны на этапе compositing. Но это не абсолютные гарантии: конкретный путь зависит от браузера, контекста и графического конвейера.

  • Избегай ненужных крупных и частых изменений layout.
  • Не включай will-change без измеримой причины: оно не является универсальным ускорителем.
  • Ограничивай сложные фильтры, тени и большие полупрозрачные слои там, где они создают нагрузку.
  • Используй CSS containment и content-visibility только после понимания их побочных эффектов.
  • Проверяй реальную производительность через профилировщик браузера, а не по внешнему виду кода.

17.3. Отладка в DevTools

Панель Elements/Inspector показывает DOM, применённые правила, перечёркнутые декларации, специфичность, вычисленные стили и модель коробки. Можно временно менять значения, включать и отключать декларации, смотреть Grid/Flex overlays, проверять media queries и искать источник правила.

Полезный порядок диагностики: выбери элемент → открой computed styles → выясни, какое правило задало свойство → проверь каскад и специфичность → проверь размеры родителя и режим layout → проверь stacking context, если проблема связана с наложением.

18. Что CSS не делает самостоятельно

CSS умеет описывать представление и часть реакций на состояние, но не заменяет язык программирования или браузерные API.

ЗадачаЧем обычно решается
Описать семантическую структуру документаHTML.
Оформить, выровнять и адаптировать элементыCSS.
Вычислить сложный результат по пользовательским даннымJavaScript или серверный код.

Сохранить данные в localStorage или IndexedDBJavaScript и соответствующие Web API.

Создать интерактивную графику на CanvasCanvas API и обычно JavaScript.
Изменить содержимое DOM по сложному алгоритмуJavaScript.

CSS может реагировать на состояние через селекторы, переключать визуальные варианты и даже выполнять анимации. Но для произвольных вычислений, хранения данных, сетевого обмена и сложных сценариев требуется программный код или другая часть платформы.

20. Практика и источники

Лучше осваивать CSS не запоминанием сотен свойств, а короткими экспериментами: меняй одно правило, наблюдай результат в браузере и объясняй, почему произошло именно так.

20.1. Практические задания

  1. Подключение и селекторы. Создай HTML с заголовками, абзацами, ссылками и карточками. Подключи внешний CSS. Применяй типовые, классовые, атрибутные селекторы и комбинаторы.
  2. Каскад. Задай одно свойство несколькими правилами. Предскажи результат, затем проверь специфичность, источник, слой и порядок объявлений.
  3. Box Model. Создай карточку с width, padding, border и margin. Сравни content-box и border-box.
  4. Flexbox. Сделай панель навигации с логотипом слева и группой кнопок справа. Проверь поведение при узком окне.
  5. Grid. Сделай каталог карточек, автоматически меняющий число столбцов при изменении доступного пространства.
  6. Position. Добавь бейдж в угол карточки и закреплённую шапку. Разберись с containing block и z-index.
  7. Адаптивность. Добавь media query и container query. Сравни, на какие размеры они реагируют.
  8. Темы и доступность. Добавь тёмную тему, видимый keyboard focus и режим уменьшенного движения.
  9. Анимация. Создай небольшое наведение с transition и отдельную keyframes-анимацию. Уважай prefers-reduced-motion.
