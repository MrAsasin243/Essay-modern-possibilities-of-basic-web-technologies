ВЕБ-ПЛАТФОРМА — УЧЕБНЫЙ СПРАВОЧНИК

Как открыть:
1. Распакуйте архив в любую папку.
2. Откройте index.html в браузере.
3. На главной странице выберите нужный раздел.

Содержимое:
- index.html — главная страница и навигация;
- html.html — подробный раздел HTML;
- css.html — подробный раздел CSS;
- javascript.html — подробный раздел JavaScript;
- browsers.html — подробный раздел об устройстве браузеров;
- assets/style.css — общие стили сайта.
- assets/demo.js, assets/demo.css — движок живых примеров (оболочка, проверки поддержки, кнопки «Копировать»);
- assets/demos-showcase.js — примеры главной страницы.
- assets/demos-html.js — примеры раздела HTML (19 примеров с блоками «Подводные камни и ограничения»).
- assets/demos-css.js — примеры раздела CSS (16 примеров с блоками «Подводные камни и ограничения»).

Ограничения инструментов (file://, GitHub Pages, песочница, измерения, что не проверялось) собраны на главной странице в разделе «Ограничения учебника и его инструментов».

Сайт статический: для просмотра не нужны сервер, сборка, npm или сторонние библиотеки.
Примеры, которым нужен настоящий веб-сервер, помечены и объясняют это сами; остальное работает прямо с диска.
Для проверки поддержки HTML, CSS и JavaScript-возможностей используйте MDN Browser Compatibility Data и Can I Use.
