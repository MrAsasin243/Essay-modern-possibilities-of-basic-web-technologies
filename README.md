# Layout Engine — исправление выравнивания схемы

Пакет устраняет визуальный сдвиг стрелок и неравномерность блоков в секции **«Что именно делает Layout Engine»**.

## Что меняется

- Стрелки больше не зависят от метрик символа `↓`: вертикальный стержень и наконечник рисуются CSS-псевдоэлементами относительно центра строки.
- Все этапы выравниваются по одной центральной оси.
- Основные блоки получают одинаковую ширину и минимальную высоту.
- Входные блоки используют симметричную трёхколоночную сетку: левая карточка, центральный `+`, правая карточка.
- На узком экране входные карточки перестраиваются в одну колонку, а `+` сохраняет центральное положение.
- HTML-разметка, JavaScript, остальные главы и поисковый индекс не меняются.

## Установка в Windows

1. Сделайте копию проекта или убедитесь, что Git-изменения сохранены.
2. Распакуйте содержимое ZIP **в корень репозитория** — рядом с папками `assets` и `chapters`.
3. Откройте PowerShell в корне репозитория и выполните:

   ```powershell
   python .\apply_layout_engine_fix.py
   ```

4. Откройте `chapters/layout-engine.html` в браузере и проверьте схему на широком и узком экране.

Скрипт проверяет ожидаемый маркер исходного CSS, не перезаписывает файл при несовпадении версии, создаёт резервную копию `assets/layout-engine.css.bak-*` и применяет изменение через временный файл с атомарной заменой. Повторный запуск не создаёт дубликаты.

## Ручное применение

Вместо скрипта можно дописать содержимое `layout-engine-flow-fix.css` в конец `assets/layout-engine.css`.

## Откат

Восстановите созданную резервную копию поверх `assets/layout-engine.css` либо выполните `git restore assets/layout-engine.css`, если до установки в файле не было собственных незакоммиченных изменений.

## Проверки и ограничения

Пакет рассчитан на структуру и CSS актуальной версии `main`, прочитанной при подготовке обновления. Установщик проверяет ожидаемый маркер исходного CSS, наличие новых правил и возможность повторного применения. В среде подготовки не удалось завершить запуск headless Chromium, поэтому фактическое отображение после установки следует проверить в обычном браузере на широкой и узкой ширине окна.
